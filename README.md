# Learning Linked List

This repository contains my implementations and practice problems related to **Linked Lists in C++**.

The purpose of this repository is to learn Linked Lists from scratch, understand pointer manipulation, handle edge cases, and build a strong foundation in Data Structures and Algorithms (DSA).

---

## Topics Covered

### Singly Linked List
- Create Linked List
- Insert at Beginning (`push_front`)
- Insert at End (`push_back`)
- Insert at Position
- Delete Node
- Remove Nth Node from End
- Find Size of Linked List
- Print Linked List

### Cycle Detection & Removal
- Floyd's Cycle Detection Algorithm (Tortoise and Hare)
- Detect Cycle in Linked List
- Remove Cycle from Linked List

### Doubly Linked List
- Insert at Beginning
- Insert at End
- Delete First Node
- Delete Last Node

### STL List
- `push_front()`
- `push_back()`
- `pop_front()`
- `pop_back()`
- `front()`
- `back()`
- `insert()`
- Iterators
- `advance()`
